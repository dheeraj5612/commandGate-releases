# CommandGate

An AI desktop technician connecting agents to endpoint diagnostics, approval-gated repairs, and signed audit evidence.

[Product website](https://commandgate.ai) · [Latest release](https://github.com/dheeraj5612/commandGate-releases/releases/latest) · [All releases](https://github.com/dheeraj5612/commandGate-releases/releases)

## What it does

CommandGate brings diagnostic context and repair workflows into a desktop application. The engineering focus is on connecting AI-assisted investigation to explicit approval gates and reviewable evidence of actions.

- **Diagnostics:** Give agents context about the endpoint they are investigating.
- **Approval-gated repairs:** Put approval into the repair workflow.
- **Audit evidence:** Produce signed evidence for review.

Built with **React, TypeScript, Tauri, and Rust**.
